# CRUD de Tarefas - Node.js + Express + SQLite

## 📌 Descrição
Este projeto é uma API RESTful desenvolvida com Node.js, Express e SQLite, com funcionalidades de CRUD (Create, Read, Update, Delete).

## 🚀 Tecnologias utilizadas
- Node.js
- Express.js
- SQLite

## 📌 Funcionalidades
- Criar tarefa
- Listar todas as tarefas
- Buscar tarefa por ID
- Atualizar tarefa
- Deletar tarefa

## ▶️ Como executar
1. Instalar dependências:
npm install

2. Rodar o servidor:
node server.js

3. Acessar:
http://localhost:3000/tarefas

## 🧪 Testes
Testado utilizando Postman.
